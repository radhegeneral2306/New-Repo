# Sahu Samaj Bhawan — Accounting & Member Management

A web app for Sahu Samaj Bhawan to manage cash and bank records, expenses,
debtors/creditors, and a member directory.

Live: https://radhegeneral2306.github.io/New-Repo/

## Development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` and fill in your Supabase project URL and
anon/publishable key before running.

## Tech stack

Vite, React, TypeScript, Tailwind CSS, shadcn/ui, react-router-dom,
@tanstack/react-query, Supabase (Postgres + Auth + Row Level Security).
